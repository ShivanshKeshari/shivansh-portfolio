DAG Crafter: config-driven Airflow framework

Impetus · 2025–present
YAML → DAGno hand-written DAGs
Problem
Every new pipeline meant writing, testing and deploying a bespoke Airflow DAG, and one change could ripple across others.
Approach
Designed a framework that generates Airflow DAGs dynamically from YAML configs, so each pipeline is declared as data and isolated from the rest.
Result
Significantly less development, testing and deployment effort, faster iteration, and pipeline changes that stay contained.
# illustrative pipeline config
dag_id: orders_daily
schedule: "0 2 * * *"
tasks:
  - id: load_raw
    type: gcs_to_bq
  - id: transform
    type: bq_sql
    depends_on: [load_raw]
  - id: dq_check
    type: quality
    depends_on: [transform]
